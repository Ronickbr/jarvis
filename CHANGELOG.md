## [0.1.0] - 2026-09-08

### Adicionado

- HUD web responsivo com conversa por texto, entrada de voz do navegador e síntese de fala.
- API FastAPI com modo demonstração e integração para OpenAI, Anthropic, Gemini e xAI.
- Roteamento automático por tipo de tarefa e seleção manual de provedor.
- Registro persistente, classificação de risco, aprovação e auditoria de tools.
- Executor Docker sem rede, somente leitura e com limites de recursos.
- Shell desktop Tauri, Docker Compose, testes automatizados e pipeline de CI.
